3. 통신의 구분: 앱 자체 통신, Google Play·Android 통신, 사용자가 여는 외부 웹페이지

가. 앱 자체 통신

  • 이 빌드(A단계)는 앱이 스스로 회사나 다른 회사의 서버로 데이터(이용 기록·오류 보고·식별자·광고 ID·위치·연락처 등)를 보내지 않도록 설정했습니다.
  • 앱 코드와 빌드 설정에서 확인한 내용: 게임 코드에는 서버로 요청을 보내는 기능이 없습니다. 원격 분석(Google Analytics for Firebase), 오류 자동 보고(Crashlytics), 원격 설정(Remote Config), 광고(AdMob), 인앱 결제의 라이브러리 파일은 앱에 포함되어 있으나, 이 빌드는 이들을 시작하지 않도록 설정했고, 자동으로 시작하는 구성요소와 광고 ID 권한·결제 권한은 빌드 설정에서 뺐습니다. 알림은 기기 안에서 예약하는 알림이며 서버 푸시를 쓰지 않습니다(2항).
  • 이 내용은 앱 코드·빌드 설정 검토와 에뮬레이터 시험을 바탕으로 한 것입니다. 이런 확인은 특정 기기·시점의 관측이며, 모든 기기·상황에서의 보증이 아닙니다.

나. Google Play·Android 통신 (앱과 별개)

  • 테스터가 Google Play에서 테스트에 참여하고 앱을 내려받고 업데이트하는 과정, Google Play 서비스와 Google Play 프로텍트 같은 보안 점검, Android 운영체제의 기능(백업·기기 이전, 알림 표시 등)은 Google과 기기 제조사가 앱과 별개로 수행합니다. 이 처리는 회사가 통제하지 않으며 Google 개인정보처리방침과 기기 제조사의 방침을 따릅니다.
  • 회사는 Play Console에서 설치 수·기기 종류·비정상 종료 같은 Google이 집계해 개발자에게 제공하는 통계를 볼 수 있습니다. 회사는 이 통계로 개별 테스터를 찾으려 하지 않습니다.

다. 사용자가 직접 여는 외부 웹페이지와 메일

  • 앱의 설정 > 개인정보 화면에서 "개인정보처리방침 보기"를 누르면 기기의 웹 브라우저가 이 방침 페이지(https://onetry-co.github.io/privacy/)를 엽니다. 이 페이지는 GitHub Pages(GitHub, Inc., 미국)로 제공되며, 페이지를 열 때 GitHub가 처리하는 접속 정보는 5항 다.에 적습니다. 회사는 이 페이지에 쿠키·분석 도구·외부 스크립트를 넣지 않았습니다. 이 방침 안의 다른 사이트 링크(예: Google 개인정보처리방침)도 사용자가 누를 때만 열립니다.
  • 같은 화면의 "삭제 요청 메일 쓰기"를 누르면 기기의 메일 앱이 열리고 받는 사람(privacy@onetry.co.kr)·제목·내용(앱 버전, 그리고 이전 테스트 버전에서 통계를 켠 적이 있어 기기에 남아 있으면 그때의 분석 ID(앱 인스턴스 ID·Firebase 설치 ID))이 미리 채워집니다. 앱이 메일을 보내지 않으며, 사용자가 메일 앱에서 보낼 때만 사용자의 메일 서비스를 통해 전송됩니다. 받은 메일은 7항 기준으로 보관합니다.

앱은 웹 쿠키, Android 광고 ID, 정밀 위치를 이용하지 않습니다.

분석 ID의 구분: ① A단계 빌드는 새 분석 식별자를 만들지 않고, 어떤 식별자도 이용자 추적에 쓰지 않습니다. ② 다만 같은 기기에 이전 테스트 버전(통계를 켠 적이 있는 버전)에서 만들어진 분석 ID가 남아 있으면, 그 ID가 삭제 요청 메일에 들어갈 수 있습니다. 회사는 이 ID를 이전 테스트 때 쌓인 데이터를 찾아 지우는 데에만 씁니다. ③ 이전 테스트 버전(A단계 전, 통계를 켰던 버전)이 수집한 분석 데이터는 Google LLC(미국)의 Firebase·Google Analytics에 보관되어 있습니다. 항목은 Firebase Analytics가 기본으로 수집하는 범위인 분석 ID(앱 인스턴스 ID·Firebase 설치 ID), 게임 이용 이벤트, 기기·앱 버전 정보, 대략적인 국가입니다. 이전 테스트를 분석하려고 수집했으며, A단계 빌드는 새로 수집하지 않습니다. 이 데이터는 보관 설정(이벤트 데이터 2개월, 사용자 수준 데이터 2개월)에 따라 자동으로 삭제되며, 삭제를 요청하면 분석 ID로 찾아 삭제합니다. 국외 이전 내용은 5항 라.에 적습니다.

5. 처리 위탁과 국외 이전

가. 게임 앱 자체 전송: 없음

A단계 빌드는 앱이 스스로 회사나 다른 회사의 서버로 데이터를 보내지 않도록 설정했습니다(3항 가.). 따라서 A단계 빌드 이용과 관련해 회사가 개인정보를 처리 위탁하거나 국외로 이전하는 일은 없습니다(이전 테스트 버전 때 수집된 분석 데이터는 라.). A단계에서는 테스터 정보를 Play Console에 입력하지 않습니다.

나. 회사가 이용하는 외부 서비스
